## 🚀 Current Projects

### ✍️ Romanziere Studio `🔒 Private`

A local-first desktop environment for planning, writing and managing complex novels.

It combines manuscript editing with a structured narrative database, research, characters, locations, timelines, relationships and AI-assisted writing workflows.

**Highlights**

- Desktop application built with **Tauri 2**
- **Rust** backend
- **React 19 + TypeScript** frontend
- **SQLite** persistent narrative database
- Full-text search with **FTS5**
- Hierarchical manuscript: parts, chapters and scenes
- Rich-text editing, autosave and recovery safeguards
- Narrative knowledge graph / **Narrative Brain**
- Timeline, corkboards, characters, locations and research library
- Verified SQLite backup and restore workflows
- Portable workspace archives with integrity checks
- Cloud and local AI providers
- Local **GGUF** model support
- Managed **llama.cpp / llama-server** integration
- Offline documentation and learning environment

**Stack:** `Rust` · `Tauri` · `React` · `TypeScript` · `SQLite` · `Vite` · `llama.cpp` · `GGUF`

🟢 **Active development**
